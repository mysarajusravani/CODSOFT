# Task 3: Image Captioning AI

## Overview

This project combines Computer Vision and Natural Language Processing (NLP) to automatically generate descriptive captions for images. The system uses a pre-trained deep learning model to identify objects and features present in an image and then generates a meaningful caption based on the detected content.

## Features

* Upload and process images.
* Extract image features using a pre-trained CNN model (MobileNetV2 / VGG16 / ResNet).
* Generate descriptive captions for images.
* Visualize uploaded images along with predicted captions.
* Easy-to-use implementation in Google Colab or Jupyter Notebook.

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Google Colab

## Project Workflow

1. Upload an image.
2. Preprocess the image for the neural network.
3. Extract image features using a pre-trained CNN model.
4. Generate predictions from the model.
5. Convert predictions into a human-readable caption.
6. Display the image with the generated caption.

## Usage

1. Open the notebook `image_captioning.ipynb`.
2. Run all cells sequentially.
3. Upload an image when prompted.
4. The model will analyze the image and generate a caption.

## Example

**Input Image:** Flower Image

**Generated Caption:** "This image contains a barn."
