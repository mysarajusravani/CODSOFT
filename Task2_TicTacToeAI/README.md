# Tic-Tac-Toe AI

## Overview

This project is a Python-based Tic-Tac-Toe game where a human player competes against an AI opponent. The AI uses the Minimax algorithm to make optimal decisions, making it very difficult to defeat.

## Features

* Human vs AI gameplay
* Intelligent AI using Minimax Algorithm
* Winner detection
* Draw detection
* Console-based user interface
* Easy to understand and run

## Technologies Used

* Python 3
* Functions
* Minimax Algorithm
* Game Theory Concepts

## How It Works

The human player uses **X** and the AI uses **O**. The AI evaluates all possible future moves using the Minimax algorithm and selects the best move available.
