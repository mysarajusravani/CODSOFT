# Telugu Book Recommendation System

## Overview

The Telugu Book Recommendation System is a simple Python-based recommendation application that suggests Telugu books based on the user's preferred genre and minimum rating.

The system contains a collection of popular Telugu books from different genres such as Biography, Comedy, Drama, Mythology, Novel, Poetry, Romance, and Stories. Users can select a genre and specify a minimum rating to receive personalized book recommendations.

---

## Features

* Genre-based book recommendations
* Rating-based filtering
* User-friendly command-line interface
* Input validation for ratings
* Multiple recommendation sessions
* Supports various Telugu literary genres

## How It Works

1. The system displays all available genres.
2. The user selects a preferred genre.
3. The user enters a minimum rating between 1.0 and 5.0.
4. The system searches the book collection.
5. Matching books are displayed with their ratings.
6. The user can continue searching or exit the application.
