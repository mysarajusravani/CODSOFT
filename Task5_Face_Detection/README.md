# Task 5: Face Detection and Recognition

## Overview

This project focuses on developing an AI-based Face Detection and Recognition system. The application can detect human faces in images or videos and optionally recognize known individuals using machine learning and deep learning techniques. Face detection is performed using pre-trained models such as Haar Cascades or Deep Learning-based detectors, while face recognition can be implemented using advanced methods like Siamese Networks or ArcFace.

## Features

* Detect faces in images and videos.
* Real-time face detection using a webcam.
* Face localization with bounding boxes.
* Face recognition of known individuals.
* Support for multiple faces in a single frame.
* High accuracy using pre-trained models.

## Technologies Used

* Python
* OpenCV
* NumPy
* Haar Cascade Classifier
* Deep Learning Models
* TensorFlow / Keras
* Face Recognition Library

## Project Workflow

1. Load image, video, or webcam feed.
2. Detect faces using a pre-trained face detector.
3. Extract facial features.
4. Compare extracted features with stored face embeddings.
5. Recognize and identify the person.
6. Display results with bounding boxes and names.

## Usage

1. Run the Python script or Jupyter Notebook.
2. Provide an image/video or use a webcam.
3. The system detects faces automatically.
4. Recognized faces are labeled with their names.

## Example

### Input

Image containing one or more human faces.

### Output

* Face detected successfully.
* Bounding box drawn around each face.
* Name displayed if the face matches a known person.
